# WardenOS (2D OS site)

The retro desktop that appears on the monitor inside the 3D room. It is a React app based on Henry Heffernan's open-source [portfolio-inner-site](https://github.com/henryjeff/portfolio-inner-site) (MIT license).

Edit your content in `src/components/showcase/` (Home, About, Experience = Journey, Projects, Contact, and `projects/Games|Programs|Web`).

```bash
npm install --legacy-peer-deps
npm start          # dev server on http://localhost:3000
```

To put your changes into the 3D site, run `npm run build:os` from the **parent** folder.
